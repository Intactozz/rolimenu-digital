# Rolih Pasteis Digital Menu

Crie um site de cardápio digital para um restaurante, com design moderno, elegante e totalmente responsivo (prioridade para boa experiência no celular, já que a maioria dos clientes vai acessar via QR code na mesa ou link do WhatsApp).

Sobre o restaurante

Nome: Rolih Pasteis

Tipo de cozinha: Pastelaria com molhos

Atmosfera/estilo: Familiar com toques laranjas

Slogan (opcional): Um menino feliz comendo pasteis

Estrutura do site

Header/Hero — nome do restaurante, logo, uma frase de impacto e uma imagem de fundo apetitosa (foto de prato ou do ambiente)

Cardápio — itens organizados por categorias (dos mais baratos ao mais caro e Bebidas), cada um com nome, descrição curta, preço e espaço para foto, tendo no cardapio os seguintes: Tradicional sendo Carne, queijo, pizza (15 reais) bauro, frango (13 reais). Os especiais sendo frango com requeijão, frango com queijo, carne com queijo, carne com ovo (18 reais)

Destaques — seção no topo do cardápio com os 3-4 pratos mais pedidos ou favoritos da casa

Sobre nós — parágrafo curto contando a história ou o diferencial do restaurante

Horário e localização — funcionamento das 16h às 00h, localizado na rua doutor carlos ubaldino bueno de abreu, 175 

Contato — botão de WhatsApp para quando for concluir o pedido ir para o WhatsApp concluir o pedido conosco junto com o que vão comprar, mais ícones de redes sociais

Footer — informações de contato e copyright

Design

Paleta de cores: laranja com preto 

Tipografia: fonte serifada para títulos (elegância) + fonte sans-serif limpa para o corpo do texto

Cards com sombra sutil e cantos arredondados para os itens do cardápio

Navegação fixa no topo com links de scroll suave até cada categoria

Funcionalidades

Menu com navegação por abas ou scroll suave entre categorias

Animações suaves ao rolar a página (fade-in nos itens)

Layout mobile-first, testado para ficar perfeito em telas pequenas

Preencha o cardápio com dados fictícios realistas (nomes de pratos, descrições e preços) como exemplo, para eu poder ver o resultado completo e depois substituir pelo conteúdo real.
